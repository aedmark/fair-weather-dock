# High & Dry: The Fair-Weather Dock

An interactive maritime physics diorama for stress-testing fair-weather friends with heavy couches, sudden squalls, radio silence, itemized dinner checks, and 5:00 AM Terminal B airport runs.

Built on Pier No. 04 by **The Triad** (`Graham`, `Ziggy`, and `Jade`).

## Running Locally or Hosting

Zero build step and zero runtime dependencies. Open `index.html` directly in any browser, or serve the folder statically:

```bash
python3 -m http.server 8080
```

## Controls

- **Click the pier** (or press `I`) to invite a new guest onto the planks.
- **Type an optional nickname** before inviting if you want the Harbor Log to record evacuations by name.
- **Poke** a guest to hear what they are actually made of, or **drag & flick** them toward Excuse Sea.
- **Run Stress Tests (`1`–`5`)**:
  1. `Move a Couch`
  2. `Make It Rain`
  3. `Stop Texting First`
  4. `Split the Check`
  5. `5 AM Airport Run`
- **Click the rubber duck** in Excuse Sea for moral support.
