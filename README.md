# High & Dry: The Fair-Weather Dock

An interactive maritime parable and crowd-driven Web Audio harbor band about our collective fair-weather habits, heavy couches, mutual ballast, and showing up first.

> *"Show up for the ones who stay. Stay for the ones who show up."*

Built on Pier No. 04 by **The Triad** (`Graham`, `Ziggy`, and `Jade`), with zero-sample procedural synth voices adapted from **The Whimsy Machine** and multi-section track arrangements (`sections` + `order()` key changes and part mutes) adapted from **Bespoke**.

## Running Locally or Hosting

Zero build step and zero runtime dependencies. Open `index.html` directly in any browser, or serve the folder statically:

```bash
python3 -m http.server 8080
```

## Controls

- **Click the pier** (or press `I`) to invite a friend onto the planks.
- **Click incoming flares (`[!]`)** above a friend—or use **Show Up First (`Q` / `W` / `E` / `S`)**—to send a zero-pressure check-in text, put on hot soup, share yellow slickers, or pitch in early. Showing up builds mutual **Ballast**, helping overwhelmed friends anchor to the planks and play steady in the band through any storm.
- **Life Happens (`1`–`5`)**:
  1. `Move a Couch`
  2. `Make It Rain`
  3. `Go Quiet 2 Weeks`
  4. `Split the Check`
  5. `5 AM Airport Run`
- **Tune the Pier Radio (`T` or click the bench radio)** to cycle **Auto DJ**, **Sea Shanty**, **Pier Bossa**, **Harbor Lo-Fi**, **Boardwalk Rag**, and **Off**.
- **Click the rubber duck** in Excuse Sea for morale.
